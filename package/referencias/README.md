# Referencias

Guarde aquí mockups, capturas, imágenes, videos o documentos PDF utilizados como referencia. Para redactar copy desde un PDF, indique el archivo y, si es extenso, las páginas o apartados relevantes; el agente extraerá solo los hechos necesarios para la sección.

Recomendación de nombres:

```text
home-01-hero-desktop.png
home-01-hero-tablet.png
home-01-hero-mobile.png
home-02-beneficios-desktop.png
```

Registre cada archivo en la tabla de referencias de `PROJECT_CONTEXT.md`. Una referencia solo es autoritativa para la página, sección y dispositivo indicados.
