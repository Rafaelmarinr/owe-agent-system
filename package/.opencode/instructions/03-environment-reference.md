# PROJECT_ENVIRONMENT.md

`PROJECT_ENVIRONMENT.md` es una referencia técnica opcional creada por `/wp-environment`.

No leerlo automáticamente al iniciar una conversación, planificar, delegar o comenzar una sección.

Leerlo solo cuando:

- la tarea dependa estrictamente de versiones de WordPress, PHP, plugins o tema;
- sea necesario conocer si existe Git y su estado;
- el usuario solicite revisar el entorno.

La fecha es solo informativa. No tiene caducidad y nunca justifica por sí sola solicitar una actualización. No exigir ejecutar `/wp-environment` para continuar.
